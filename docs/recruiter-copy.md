## LinkedIn project description

Designed a multi-source customer-review workflow using n8n, PostgreSQL/Neon, LLM classification, and brand-guided response drafting with DeepSeek via OpenRouter. The system combined daytime operator approval and an after-hours automatic mode, expert confirmation for photo-based defect findings, deterministic compensation/replacement calculations, and channel-specific publication verification. Ozon, Wildberries, and Telegram used API publishing; other sites used a Python HTTP service with a fresh Chrome instance per task. Technical failures alerted an operator for manual repair. This public case study reconstructs the architecture because the original workflow exports are unavailable. The operator's self-reported manual effort fell from roughly 6 hours/day to 1 hour, then about 15 minutes as review volume grew; these figures were not independently measured.
